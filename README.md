# Datto

现代化的 Windows 剪贴板工具。使用 C# / WPF（.NET 10）。

## 项目结构

- Datto.slnx：解决方案入口，可在仓库根目录执行 `dotnet build`。
- src/Datto/：WPF 应用项目，App.xaml / App.xaml.cs 负责应用入口。
  - Views/：主窗口及设置、主题切换、剪贴板交互代码。
  - Models/：剪贴板记录 Clip 和用户设置 Preferences。
  - Clipboard/：系统剪贴板格式读取、转换和写入。
  - Themes/：共享控件样式，包括菜单、按钮和滚动条。
  - Diagnostics/：内置格式回归检查，通过 `--format-test` 执行。
  - Assets/：应用图标等资源。
- build/：图标生成、发布和安装脚本。
- dist/：生成的发布文件和安装包（不纳入版本控制）。
- Start-Datto.cmd：本地调试构建的启动入口。

## 构建与运行

安装 .NET 10 SDK 后：

```powershell
dotnet build
dotnet run --project src/Datto/Datto.csproj
```

也可以直接运行构建生成的 src/Datto/bin/Debug/net10.0-windows/Datto.exe，需要 .NET 10 Desktop Runtime。

## 使用

- Windows 剪贴板变更事件监听，无定时轮询。文本、链接、图片、文件/文件夹及 HTML/RTF 富文本自动保存，去重后置顶。
- 底部横向预览卡片、全文搜索、收藏、删除，最近收录或使用的记录在前；从历史复制或快速粘贴时，成功写入剪贴板后原记录前移，不重复新增，重启后保留顺序；仅查看预览不改变排序。默认最多保留 500 条普通记录，可在设置中调整，优先保留最近使用的记录，收藏单独保留。
- 关闭窗口或 Esc 隐藏到托盘，托盘菜单“退出”才会结束监听。
- Ctrl + Shift + V 呼出，Ctrl + K 搜索；搜索框按 ↓ 进入卡片，← → 选择，空格打开完整预览，Esc 关闭预览。Enter 和双击卡片都会直接粘贴回唤起前的应用并收起面板。
- 右键卡片可复制、预览、收藏 / 取消收藏、删除；顶部可切换全部与收藏。
- 历史以明文保存在 %LOCALAPPDATA%/Datto/history.json，请避免复制敏感信息。

图片保存为 PNG，卡片显示缩略图，空格查看大图；HTML/RTF 保留原格式供粘贴，预览使用可用的纯文本内容。文件/文件夹仅保存路径，不备份文件内容，移动或删除原文件后无法粘贴；从历史粘贴文件按复制处理。单条内容上限 20 MB，图片上限 4000 万像素，超过时状态栏提示。图片内容与富文本随历史保存在本地，旧版文本历史可继续读取。Enter、双击卡片和 Ctrl+1–9 支持自动粘贴；右键菜单的“复制”只复制。快捷键冲突会在状态栏提示，可从托盘打开。


尚未做真实机器的冷启动、呼出耗时和常驻内存基准测试。


可在资源管理器中双击根目录 Start-Datto.cmd 启动。应用启动异常会显示提示，并写入 %TEMP%/Datto-startup-error.log。开发检查：Datto.exe --smoke-test 会显示窗口，完成渲染后自动退出（不测试剪贴板操作）。

外观默认跟随 Windows 应用颜色模式；托盘右键 → 外观可选择跟随系统、浅色、深色，选择自动保存。深浅色均保留半透明面板，卡片和完整预览使用独立配色。


## 设置

从浮层右上角齿轮或托盘菜单打开。修改后点击“保存设置”。

- 开机启动：默认关闭；启用后通过当前用户 Windows Run 启动项在登录时以 --background 驻留托盘。没有管理员权限要求。移动程序目录后需重新关闭、启用此项。
- 唤起快捷键：点击输入框后按组合键，支持 Ctrl / Alt / Shift + 字母、数字或 F1–F12。保存时检测冲突，冲突时原快捷键不变。
- 最大历史数量：50–10,000 条普通记录，收藏不计入。缩小上限会先确认将移除的数量。
- 数据统计：当前保留的总记录、收藏、链接数量和历史序列化大小，每两秒刷新。
- 设置保存于 %LOCALAPPDATA%/Datto/settings.json。外观设置仍可通过托盘“外观”菜单选择。

界面回归检查：Datto.exe --smoke-test --settings（附加 --dark 检查深色）。测试使用内存示例，不保存设置或注册开机启动项，完成后自动退出。


## 监听与快速粘贴

- 浮层右上角、托盘菜单或设置中的暂停按钮可停止 / 恢复监听。暂停仅影响采集，现有记录仍可使用；恢复后只收录新复制的内容，不补录暂停期间内容。暂停状态本次运行有效，重启恢复监听。
- 设置中按行填写排除应用进程名（例如 KeePass.exe），保存生效。忽略大小写和 .exe 后缀。按剪贴板所有者进程判断；有排除规则且来源无法识别时不采集。规则不追溯删除历史。
- 自动尊重剪贴板忽略标记：包含 `Clipboard Viewer Ignore`、`ExcludeClipboardContentFromMonitorProcessing`，或 `CanIncludeInClipboardHistory` 的 DWORD 值为 0 时，不读取内容或保存历史。适用于主动提供标记的临时取词、密码管理等软件；未提供标记的模拟复制无法据此识别。仅含 `CanUploadToCloudClipboard=0`（禁止云同步）仍可保存本地历史。
- 设置中“清空历史”默认保留收藏，可取消勾选以同时删除收藏。删除前确认，系统剪贴板内容不变。
- 在目标应用中用全局快捷键唤起面板，Ctrl+1–9（含数字小键盘）将当前搜索 / 筛选结果的第 1–9 项复制、收起面板并向原应用发送 Ctrl+V。数字角标标识对应项。不足九项时无效编号无操作。
- 自动粘贴等待修饰键释放；目标窗口失效、焦点改变时取消。向管理员权限应用发送按键可能被 Windows 拒绝，此时可手动 Ctrl+V。应用内不接受粘贴的控件不会因此变得可粘贴。

## 启动与安装包

默认启动（包括双击 exe）仅驻留系统托盘，不打开主面板。通过全局快捷键、托盘双击或“打开 Datto”唤起；--show 可显式打开面板，开始菜单入口使用该参数。--background 保留兼容。

构建安装包：

```powershell
./build/Build-Installer.ps1
```

输出 dist/Datto-Setup-0.1.4-x64.exe。构建需要 Windows、.NET 10 SDK、Inno Setup 6.5+。从 https://jrsoftware.org/isdl.php 安装 Inno Setup，也可使用 -IsccPath 指定 ISCC.exe。

安装器使用 Inno Setup 标准安装向导，支持安装目录选择、开始菜单、可选桌面快捷方式、覆盖升级和系统卸载。默认按当前用户安装至 %LOCALAPPDATA%/Programs/Datto，无需管理员权限。安装完成后默认勾选启动并驻留托盘，可取消勾选。使用固定 AppId 识别后续升级。

旧版自制安装器已移除；新安装器成功安装后清理旧版卸载注册项，保留用户数据和设置。卸载会移除本应用的开机启动项，但不删除历史。当前应用仍需 x64 .NET 10 Desktop Runtime；安装前检查运行时，缺少时提供官方地址。安装包尚未签名。

图标源生成脚本：build/New-Icon.ps1；产物：src/Datto/Assets/Datto.ico，包含 16–256 像素多尺寸。


面板切换到其他应用时自动隐藏；设置、完整预览与右键菜单保持可操作。每次唤起不默认选中卡片，点击或方向键选择后显示选中边框；未选择时 Enter 粘贴当前结果第一项。
